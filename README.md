# TRK GOAT - Updates & Downloads

Official update channel for the TRK GOAT fitness app.

## Download Latest

Go to the [Releases](https://github.com/shinra420070186-crypto/trk-goat-updates/releases) page and download the latest APK.

## How Updates Work

The app checks for updates from **Settings > Check for updates**. Updates download as small patch files when possible, or the full APK when needed.
